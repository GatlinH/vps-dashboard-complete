## 原设计（agy 原文）

COLD_HUD_DESIGN_CONTRACT

本设计合同为前端设计者 agy 针对资产总览页面（Overview）由 LCARS 视觉重构为“冷色高精 HUD（Cold High-Density HUD）”所制定的硬性设计约束规范。本合同作为后续编码与测试用例编写的唯一视觉依据。

### 一、 关键设计决策

#### 1. 布局结构恢复（撤销 LCARS 变形，回归原验收紧凑流）
*   **消除侧栏侵入**：彻底废弃桌面端 `80px` 与平板端 `60px` 的左侧保留内边距。页面主容器恢复为对称居中容器，桌面端边距固定为 `padding: 12px 24px 0`，最大宽度约束为 `1440px`；移动端（`<768px`）恢复为 `padding: 12px 12px 0`。
*   **网格栅格对称复位**：
    *   桌面端（`>=1280px`）：10 项摘要卡片与节点列表完全恢复为 `repeat(4, minmax(0, 1fr))` 对称 4 列网格，列与行间距统一恢复为 `16px`（撤销 LCARS 强制改为的 `row-gap: 8px`）；`cost`（月度费用）与 `expiry`（到期与状态）强约束保留跨 2 列（`grid-column: span 2`）。
    *   平板端（`768px ~ 1279px`）：摘要卡片与节点卡片均降级为对称 2 列（`repeat(2, minmax(0, 1fr))`）。
    *   移动端（`<768px`）：摘要卡片维持紧凑 2 列，网格间距收紧为 `12px`；节点列表卡片单列全宽（`1fr`）纵向排列。
*   **绝对禁止外框包裹**：页面不设任何全局外框、不设侧边物理轨道条（Rail）、不设顶部大梁（Beam）与弧形弯头（Elbow）。视口左右与顶部空间完全释放给数据呈现。

#### 2. HUD 装饰机制（轻量、低噪、受控发光与无破坏性裁切）
*   **彻底禁用全局 `clip-path` 裁切**：严禁在卡片外层容器或主交互容器上使用 `clip-path`（防止截断键盘 `:focus-visible` 焦点环、下拉菜单浮层以及 Tooltip 阴影）。
*   **轻量角标与括号装饰**：卡片 HUD 科技感完全通过子伪元素（`::before` / `::after`）实现局部点缀，所有装饰节点强制声明 `pointer-events: none`。
    *   卡片倒角统一采用科技感微圆角（`border-radius: 4px`），去除 LCARS 的非对称胶囊圆角（`18px 0 0 18px`）。
    *   装饰线使用 `1px` 细青描边，四角可挂载微型高光包角（4px × 4px 静态 L 型青色折角），透明度受控在 `0.4 ~ 0.8`。
*   **静态发光与字迹保真**：全面取缔扫描线动画、荧光呼吸频闪与重度模糊滤镜。发光仅允许静态点阵与微弱边缘晕染（卡片外发光限制在 `0 0 8px rgba(0, 229, 255, 0.15)` 以内；指标数字等宽数值文字严禁叠加多层 `text-shadow`，仅允许单层紧凑高光 `0 0 4px rgba(0, 229, 255, 0.35)`），杜绝任何文字泛白糊边与视认度下降。

#### 3. 设计 Token 与字型规范（极夜深蓝黑 + 冷青主调）
*   **深色模式（Bridge / 默认 HUD）**：
    *   `--hud-bg`: `#060913`（近黑深蓝黑底色，替换 LCARS 的纯黑 `#000`）。
    *   `--hud-panel`: `rgba(10, 20, 36, 0.72)`（微透冷深蓝面板，带 `backdrop-filter: blur(12px)`）。
    *   `--hud-border`: `rgba(0, 229, 255, 0.28)`（冷青细描边）。
    *   `--hud-cyan-primary`: `#00e5ff`（高亮电光青，用于主标题、核心数值、激活态、进度条亮部）。
    *   `--hud-cyan-dim`: `#0090b0`（暗青色，用于副标题标签、未激活刻度、网状基准线）。
    *   `--hud-text-primary`: `#e2e8f0`（冷白/浅灰，用于主要正文与长文本）。
    *   `--hud-text-muted`: `#7289a5`（低饱和蓝灰，用于规格辅助说明、更新时间、离线节点事实）。
    *   `--hud-glow`: `0 0 8px rgba(0, 229, 255, 0.22)`。
*   **浅色模式（Daylight 对应冷色调）**：
    *   `--hud-bg`: `#ecf2f8`（冷灰冰白底色）。
    *   `--hud-panel`: `rgba(255, 255, 255, 0.88)`（高反射冷白磨砂面板）。
    *   `--hud-border`: `rgba(8, 145, 178, 0.35)`（湖青细边框）。
    *   `--hud-cyan-primary`: `#0891b2`（深调青色，保证浅底文本对比度满足 WCAG AA 4.5:1）。
    *   `--hud-text-primary`: `#0f172a`（深墨蓝正文）。
    *   `--hud-text-muted`: `#475569`（冷石灰说明）。
*   **字型与排印体系**：
    *   正文无衬线：优先回退至系统高可读字体族 `system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", sans-serif`。
    *   数字等宽与数据感：数值、时延、百分比强制声明 `font-variant-numeric: tabular-nums`，字体优先选用 `"JetBrains Mono", "Roboto Condensed", "DIN Alternate", monospace`，确保在中文长字段或 0/1/4/30 节点伸缩时，多行数字完全垂向对齐，杜绝宽度晃动。

#### 4. 交互控件与移动端基底（触控安全性与展开容错）
*   **基础交互尺寸**：返回按钮、主题开关、语言下拉框、币种切换按钮、过滤 Tab、排序按钮以及摘要卡片折叠展开按钮（`<summary>`），其有效点击热区高度与宽度均不得小于 `36px`。
*   **控件形态**：按钮弃用 LCARS 的单侧大圆弧半胶囊（`14px 0 0 14px`），改用对称倒角或倒切小角几何体（`border-radius: 4px`），激活态以青色描边高亮 + 内部浅青底色（`rgba(0, 229, 255, 0.16)`）表达选中状态。
*   **卡片折叠展开容器**：摘要卡片的 `<details>` 展开区域支持自动高度伸展，`overflow` 维持 `visible`，当节点数达到 30 或处于中文冗长分组说明时，展开面板内容纵向自然撑开，卡片内部与网格不出现内容被裁断、文本重叠或水平溢出滚条。
*   **移动端底部 Dock 留白**：在 `<768px` 视口下，页面最外层底部必须维持恒定 `padding-bottom: calc(52px + 16px + env(safe-area-inset-bottom, 0px))`，严禁因移除 LCARS 或调整 HUD 面板而改变此避让距离，确保底栏 4 项导航（后台/资产/详情/地球）绝不遮挡最后一张卡片及其 PING 区域。

### 三、 断言交接与隔离矩阵

#### 1. 被用户方向确立替换的旧视觉断言（废弃列表）
*   ~~**断言 LCARS-V01**~~：页面左内边距必须存在 `80px`（桌面端）或 `60px`（平板端）物理避让区。 -> **替换为**：桌面端左右对称 `24px`，无任何侧边单边塌陷。
*   ~~**断言 LCARS-V02**~~：DOM 树内必须渲染 `.lcars-frame` 且包含 `.lcars-elbow`、`.lcars-beam` 与 `.lcars-rail`。 -> **替换为**：DOM 树不挂载上述轨道结构，HUD 装饰仅由卡片内部微角标实现。
*   ~~**断言 LCARS-V03**~~：基色调必须包含 Starfleet 标志性橙色（`#ff9900`）、浅紫（`#9999ff`）与桃色（`#ff9966`）。 -> **替换为**：冷色 HUD 体系（深蓝黑 `#060913` 底色 + 电光青 `#00e5ff` + 冰蓝白正文）。
*   ~~**断言 LCARS-V04**~~：卡片与按钮必须呈现非对称单侧圆弧（如 `18px 0 0 18px`）。 -> **替换为**：高精 HUD 对称小倒角（`4px`）与几何科技轮廓。
*   ~~**断言 LCARS-V05**~~：摘要卡片顶部必须挂载 4 色轮替的 `.lcars-endcap` 实体色条。 -> **替换为**：统一的 `1px` 细青光边缘与局部角标，消除杂色色块噪点。

#### 2. 原样保留的功能、数据及隔离断言（不可触碰基线）
*   **断言 CORE-F01（10 项摘要完整性）**：必须原样保留并正确计算 `nodes`、`platforms`、`cpu`、`load`、`ram`、`disk`、`rates`、`traffic`、`cost`、`expiry`，字段名与数值语义不得缺失。
*   **断言 CORE-F02（数据缺失与 0 值判定）**：真实数值 `0`（如 CPU 负载 0%、费用 ¥0）必须明确呈现为 `0`；未上报或不可用数据必须输出缺省占位符（如 `—`），严禁将缺失渲染为 0 或将 0 判定为空。
*   **断言 CORE-F03（计算器与联动交互）**：节点卡片上的“计算器”独立触发按钮、状态筛选器（全部/在线/波动/离线）、排序切换（默认/CPU/内存/网速/到期/流量）及后台分组 Tab 行为完全保留。
*   **断言 CORE-F04（单位与计费逻辑）**：PING 时延单位（`ms`）、流量基数（`KB/s`, `MB/s`, `GB`）、双币种汇率切换计算及覆盖率（如 `覆盖 4/4`）原样保留。
*   **断言 CORE-F05（隔离边界不受损）**：必须继续确保 `:where(:not(#pageRoot[data-theme-style="lcars"] *))` 对全站非资产页面的隔离有效，严禁因 HUD 样式引入 `!important` 污染外部组件。
*   **断言 CORE-F06（移动 Dock 尺寸）**：移动端底部必须稳定保留 `52px + 16px + env(safe-area-inset-bottom, 0px)` 的底部避让空间。
*   **断言 CORE-F07（严禁网络详情表复活）**：已确认剔除的旧版庞大网络详情表格绝不得重新引入。

## 源码与测量补正（agy 原文，优先）

COLD_HUD_SOURCE_AMENDMENT

本补正为前端设计者 agy 针对深蓝黑底冷青 HUD 合同的窄向技术裁决与修正案。原设计核心视觉（深蓝黑底、亮青细边、白灰正文、角括号微光、无衬线与等宽数字、紧凑卡片布局）与有效架构保持不变，现就父独立审计提出的 6 项问题做出逐项裁决，并确立最终 Token 及交付 Manifest。

---

### 一、审计事项逐项裁决

1. **真实文件路径与兼容策略裁决**
   * **废除**原合同中关于 `web/static/*` 的错误路径设定，正式绑定至 Vite 真实工程结构。
   * 明确保持 [main.css](../frontend-vite/src/styles/main.css) 与 [starfleet-theme.css](../frontend-vite/src/styles/starfleet-theme.css) 的 **byte-identical**（字节级一致）。
   * 维持 `.lcars-theme-applied` 类名挂载与旧选择器隔离 marker 不变，确保热切兼容。

2. **色彩层级分离与白昼对比度裁决**
   * **彻底拆分“装饰青”与“文本青”**：图形边框/角标不属于文本，不适用 4.5:1 文本对比度标准。
   * **白昼正文青**：废除白昼模式下将 `#0891b2` 用于正文的设定；白昼文本青选定为 **`#0b6b82`**（在合成白面板 `rgba(255,255,255,.88)` 上父独立审计测得对比度为 **6.0195:1**，在日间根底色上为 **5.4142:1**，充分满足 WCAG AA 4.5:1）。
   * **白昼装饰青**：保留 `#0891b2` 作为边框、角括弧与图表装饰。
   * **深色 HUD 文本**：保持主文字 `#e2e8f0`（对比度 16.1:1，达 AAA 7.0:1）、次要文字 `#7289a5`（5.25:1，达 AA）、暗调文本 `#0090b0`（5.05:1，达 AA）。本设计仅保障 HUD 文字及交互态达标，不扩展宣称整站 WCAG。

3. **发光 Token 与渲染收敛裁决**
   * 统一发光上限：废除 `0.22`，全系统收敛并锁定唯一发光 Alpha **`--hud-glow-alpha: 0.15`**。
   * 卡片发光限定为微光轮廓（`box-shadow: 0 0 8px rgba(0, 229, 255, 0.15)`）；数值文本仅允许单层 4px 模糊（`text-shadow: 0 0 4px rgba(0, 229, 255, 0.4)`），禁止多层光晕扩散。

4. **AC-HUD-03 尺寸容差与溢出判定裁决**
   * **废除**易被内边距与渲染引擎误报的 `scrollHeight === clientHeight` 绝对等式断言。
   * **修正标准**：`<details>` 展开及动态节点挂载时，以“容器高度自适应、无内部截断遮挡、`overflow-x: hidden` 且无水平溢出滚动条”为准；允许 1px 的 CSS 子像素（subpixel）舍入误差。所有可交互控件尺寸底线严守 **36px**（禁止为规避断言缩减尺寸）。

5. **AC-HUD-04 焦点滚入与无裁切验证裁决**
   * **废除**“未滚动前任意下屏元素焦点必须 100% 在视口”的不合理假定。
   * **修正标准**：焦点触发时先执行标准的视口对齐操作（`scrollIntoView({ block: 'nearest' })`），随后断言目标元素焦点环可见，且所有祖先节点不得有 `overflow: hidden` 或全局 `clip-path` 对其形成遮裁。
   * 卡片角标/切角必须由伪元素或 SVG 纯装饰实现，**禁止**在父级卡片根节点上通过截断溢出实现切角。高亮焦点环标准为 `outline: 2px solid var(--hud-focus); outline-offset: 2px`。

6. **原始几何恢复与遗留断言清理裁决**
   * 恢复紧凑布局原貌：
     * **≥1280px**：4 列网格，`gap: 16px`；“月度费用”与“到期与状态”各占 2 列（`grid-column: span 2`）。
     * **768px ~ 1279px**：2 列网格，`gap: 16px`。
     * **<768px**：汇总区 2 列（`gap: 12px`），节点卡片区 1 列。
     * 容器左右内边距：桌面端 24px，移动端 12px；页面全局 `max-width: 1440px`。
   * **剔除**依赖旧 436px 虚拟固定高度的过时断言；**全量保留**控制项响应、覆盖率（Coverage）、未知（Unknown）状态、零值（0）的完整性渲染测试。
