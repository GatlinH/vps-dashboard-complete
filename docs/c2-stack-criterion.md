## 错误覆盖与边界

| 错误实现或坏证据 | 保留的拒绝条件 |
| --- | --- |
| 按钮被移除、失去命中、内圈出现漏点 | C3 中心缺失、首次缺失半径、重入；六点缺失同时触发 C2 |
| 裁剪被去掉、半径缩小、方向边界偏差过大 | C3 半径包络与 spread；C9 仍须杀死变异并在恢复后全 PASS |
| 六点处按钮被其他层遮挡、地球抢占月球探针 | C2 栈首与模型/目标不符，或月球探针栈内出现 earth |
| 数量不足、空集、错误方向/坐标、状态或实例不符、产物来源不符 | 原 C0/C1 检查保持；不会因没有分歧而空集通过 |
| top/stack 改动后未相应记录一致性标记 | C0_NATIVE_API_REFERENCE；原先误归为 C2 的坏标记仍被拒绝 |
| top 不在栈内且是未登记 ID | C0_UNKNOWN_ID，显式保留旧的相等要求曾间接提供的 ID 保护 |

旧的一致性断言从未能单独证明哪一个 API 正确，也无法识别两 API 同时错误。
删除它不会放过上述甲1定义的几何和六点归属违规。各项断言仍以浏览器原生记录为输入，
没有用模型值代替实测。

检测能力并非完全等价：如果只有单元素 API 的参考值被改为另一个已登记 ID，且一致性
标记也被同步改成自洽值，当前契约不再凭该差异判产品失败；如果只在六个归属点以外
重排栈而不改变成员，C3 也不会验证该点的遮挡顺序。这些不是甲1的成员/六点归属违规，
不能声称由 C3 兜住。原始参考列、实例见证及 SHA-256 用于追溯，不能证明采集器绝无
一致伪造。真实点击事件的派发及全域归属仍需其各自的行为断言；本切片不把未测的
C4–C8/C10 宣称为通过。
